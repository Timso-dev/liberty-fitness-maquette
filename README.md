# Liberty Fitness Aumale — maquette du nouveau site

Maquette de présentation du futur site de Liberty Fitness Aumale (salle de sport et Liberty Fun Parc).

**Voir la maquette :** https://timso-dev.github.io/liberty-fitness-maquette/

- Les formulaires n'envoient rien.
- L'« Espace gestion » (lien en bas de page) montre ce que le club pourra modifier lui-même : bandeau d'information, planning de la semaine, étiquettes des cours. Les changements restent dans le navigateur de la personne qui les fait.
- Le site n'est pas indexé par les moteurs de recherche.

Les textes, photos et le logo appartiennent à Liberty Fitness Aumale (DREAM SPORT SARL).
